# SmartRouteOS media sources

Captured on 2026-08-14 (America/Toronto) from the public first-party website at <https://www.smartrouteos.com/>. These captures contain only the publicly rendered landing page; no authenticated routes, private workspaces, or customer data were accessed.

## Files

- `landing.webp` — public landing-page hero, including the product positioning, description, and public calls to action. Captured at 1280 CSS pixels with a device pixel ratio of 2, then losslessly cropped and encoded as a 2560×1280 WebP image.
- `decision.webp` — exact crop of the public “Live decision” panel showing the selected model and the quality, cost, and provider-health checks. Captured at device pixel ratio 2 and losslessly encoded as a 1960×938 WebP image.
- `logo.svg` — first-party RouteOS favicon from <https://www.smartrouteos.com/favicon.svg?v=2>. The source SVG uses a 64×64 view box.

The project owner requested these first-party assets for use in this portfolio.
