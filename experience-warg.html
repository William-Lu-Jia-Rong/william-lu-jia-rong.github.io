Waterloo Aerial Robotics Group · Oct 2024–Present

Flight software for aircraft that have to behave predictably.

As an Embedded Flight Software team member, I contribute to the control software behind WARG’s student-built drones and fixed-wing aircraft, connecting driver architecture, attitude control, and ongoing thrust-model work.

Embedded flight softwareMotor driversPID controlFlight dynamics

Three connected workstreams

Move from command to controlled motion.

Each piece addresses a different layer of the same problem: expressing motor output reliably, managing aircraft attitude, and understanding the force produced by the propulsion system.

01 · Motor driver

Build motor-driver functionality within the new architecture.

Built motor-driver functionality for WARG’s new driver architecture, creating the software path responsible for translating higher-level commands into motor behavior.

02 · Attitude manager

Shape response with PID control.

Worked on the Attitude Manager and its PID control function, a layer designed to make aircraft response stable and manageable for the pilot.

03 · Thrust model

Connect software to propulsion physics.

Work in progress models the thrust generated by the aircraft’s motors and propellers so control behavior can be reasoned about against the physical system.

Systems thinking

The interface between code and airframe matters.

Flight-control work is not isolated firmware. Drivers, control loops, propulsion assumptions, and aircraft behavior have to agree. Working across these layers has strengthened how I reason about timing, feedback, interfaces, and the physical consequences of software decisions.

Team context

Engineering inside a multidisciplinary design team.

WARG designs drones and fixed-wing aerial robots at the University of Waterloo. The embedded flight software work sits alongside electrical, mechanical, autonomy, and testing efforts, making clear communication across disciplines part of the technical job.

Current direction

Keep the model grounded.

The thrust-modeling work remains active. On this site, ongoing work is described as work in progress rather than presented as a completed flight-performance result.
