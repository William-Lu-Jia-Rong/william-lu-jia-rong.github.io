Embedded Project

Automatic Water Quality Monitoring Device

Project: Low-cost embedded water-quality monitoring platform with mobility and modular sensing.

Course Context: ECE 198

Repository: GitHub project code

STM32F401REC / C++TDS SensingMotor Control3D PrintingSystem Integration

Overview

Our team developed a cost-effective boat-based monitoring device designed to collect real-time water-quality data. The system uses TDS sensing, STM32-based control, and a modular physical design that can be extended toward wireless communication and autonomy.

What I built

  • Embedded control logic for sensor collection and system coordination.
  • Mechanical and structural design work with a custom 3D-printed enclosure.
  • Hardware integration across sensing, propulsion, and power subsystems.
  • A platform designed for future Bluetooth and autonomy upgrades.

Why it mattered

The project was aimed at making water-quality monitoring more affordable and easier to deploy, replacing slow or expensive manual sampling with a mobile, data-driven embedded system.
