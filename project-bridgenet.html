One product space for education, networking, and career discovery.

BridgeNet explored how students and job seekers could move between university search, tutoring, professional networking, and job matching in a single full-stack experience.

ReactTypeScriptNode.jsExpressPostgreSQL
AudienceStudents + job seekers
ApplicationFull-stack web platform
StatusPast / archived

Product scope

A broad problem, separated into understandable journeys.

01 · Discover

Search universities and opportunities.

The information architecture separated discovery tools by audience and intent instead of treating every user as the same generic account.

02 · Learn

Connect tutoring and guidance.

Education support was explored as part of the same journey rather than a disconnected feature surface.

03 · Network

Build relevant relationships.

Profiles and networking flows connected academic decisions with longer-term professional context.

04 · Match

Use structured data for next steps.

The backend model supported job discovery and AI-assisted guidance without making the interface depend on one undifferentiated feed.

Reflection

An early lesson in product boundaries.

BridgeNet was ambitious in scope. The useful takeaway was learning to make user groups, permissions, API responsibilities, and database relationships explicit before layering AI features on top. It remains an archived project, not an active company or current role.
